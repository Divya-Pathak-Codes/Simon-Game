# Simon-Game
An interactive Simon Game built using HTML, CSS, and JavaScript to practice DOM manipulation, event handling, game logic, and user interaction.

# Overview
The **Simon Game** is a classical cognitive memory puzzle where players replicate an ever-increasing sequence of random colors and sounds. The game dynamically generates a pattern , flashes it to the player, and waits for exceution .
This repository showcases clean separation of concerns across structural layout (**HTML**), modern interactive styling (**CSS**), and robust procedural behaviour (**JavaScript**).

---
## Key Features
- Interactive color sequence game.
- Level based gameplay.
- Random sequence generation.
- Game-over detection.

## Technologies
- **HTML** Used to build a clean accessible layout using semantic markup for the container wrapper and interactive color pads.
- **CSS** - Implements styling.
- **JavaScript** - leverages strict procedural arrays, mathematical constants, timeout functions, and event delegation patterns.

## How to play
- Start the game.
- Watch the sequence of highlighted buttons.
- Remember the Sequence.
- Click the buttons in the same order.
- Each successful round increase the level and adds to the sequence.
- If you select the wrong button, the game ends.
