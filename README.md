# Simon-Game
An interactive Simon Game built using HTML, CSS, and JavaScript to practice DOM manipulation, event handling, game logic, and user interaction.

## Features
-Interactive color sequence game.
-Level based gameplay.
-Random sequence generation.
-Game-over detection.

## Technologies
-HTML.
-CSS.
-JavaScript.

## How to play
-Start the game.
-Watch the sequence of highlighted buttons.
-Remember the Sequence.
-Click the buttons in the same order.
-Each successful round increase the level and adds to the sequence.
-If you select the wrong button, the game ends.
